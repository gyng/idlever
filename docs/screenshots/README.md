# README screenshot sources

These images are copied without edits. They show development builds, not a
promise that the hosted alpha has the same features or a verified fun score.
The README displays all three at450px height, preserving their aspect ratios.
Combat was captured at a shorter viewport than town/class skills; equal widths
previously produced a shorter middle image. The source files remain unchanged.

- town.png: Cut185 renderer capture, original earned L5/D22 town. Renderer hour
  set to noon for the screenshot; game time and gold unchanged. Source:
  docs/evidence/cut185/home-renderer/after/home-400-12.png.
- combat.png: actual first live fight on frozen8c17acb, seed211. Source:
  scratchpad/cut184/b/browser/shots/001.png, also preserved in the Cut184 original
  evidence archive. That rating was incomplete; this image gives no rating or
  active-time credit.
- class-skills.png: Cut186 button-polish capture of the original earned town,
  with three unspent class skill picks. Source:
  docs/evidence/cut186/button-ui/shots/skills-400.png. Save unchanged.

Current title artwork: web/public/art/idlever-wordmark-v1.webp, generated with
the built-in imagegen tool in the original approved style. Prompts and hashes
are recorded under art/prompts/p190_* and art/menu/idlever-wordmark-v1.json.
The original Riddle wordmark remains preserved for historical releases.
