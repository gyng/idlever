# Cut213 — staged progression and readable build outcomes

Measure the current game after automatic loot before changing its pace. The
owner wants room to try builds, fewer simultaneous early systems, and a clear
reason when a delve ends. Persistent-hero work in Cut211 changes death recovery
and must be measured against this baseline rather than called balance-neutral.

Baseline: sixteen actual new towns, manual House, public sends and actual
Porter/Scout hires, then four8h samples. Record each run's exact exit, policy
reason, actual returned Gold, tick count, unlocks, eligible plots and Journal
recommendation. No grants or forced choices. Native completion time is not a
claim about watched wall-clock time; validate the first-session journey in the
real client separately.

Acceptance targets after the baseline:

1. Scout remains available within five manual delves on all sixteen seeds and
   within15minutes in a representative real watched first session.
2. First-run town choices stay limited to the next useful step. Forge upgrades
   must not bypass manual construction; optional later facilities must not
   overwhelm the opening. Choose exact gates from measured outcomes before
   tuning. Keep Loadouts and changing owned builds free.
3. A healthy new depth record never ends the run. Record security remains real;
   Bank/Return retain all remaining Gold and death loses ordinary unprotected
   carry. Existing rules still decide actual exits; no client invented ending.
4. Every watched ending visibly names its real cause and summarizes this build's
   attempt: depth, outcome, returned/secured/lost Gold and actual policy/defeat
   reason. No unexplained disappearance or extra claim/sorting chore. Replay,
   watched and absence accounting agree exactly.
5. Measure old/current versus staged progression, stall days, early deaths and
   simultaneous decisions at matched fixed seeds. Run relevant current-game
   regression and retained exhaustive invariants after core tuning; targeted
   passes never certify omitted balance or fun.
6. Whole/sliced/reloaded catch-up remains exact and absence is never penalized.
   Current real-WASM320/400/1440 normal/200% ending and guidance journeys have
   zero overflow,44px controls and truthful state transitions. Post screenshots.

Root owns the baseline harness and Watch ending integration. Cut211 core owns
runtime engine/town/progression edits; agree numeric tuning before mutation.
Journal and depth-map lanes remain separate. The full queue stays active.
