# Superseded benchmark denominator

This first real native study completed successfully, with 40 actual seed/profile
observations and correct declared-claim intervals. Its report compared those
observations with a budget that confirmed every candidate, overstating the
savings relative to unpruned search followed by confirmation of one winner.
The final implementation compares identical winner-confirmation sample counts.
These historical reports are not final Cut280 speed/acceptance evidence. The
final real study is rerun with fresh independent seeds and the corrected runner.
