`baseline.json` / `post.json`: unchanged real-WASM802c package and exact earned
Cut203 inputs.150 cursor-changing frames per kit around the first real D1
attack, at a D7 home wall. `cost-summary.json` separates the one active-trail
leg from the zero-trail leg. GPU timer variance is not a causal performance
verdict. Heavy native/browser launches were held for the post measurement.

`visual.json` and screenshots: actual Cut203 send, step1000ticks and hero Move
t30, frozen at t37. The UI module is mounted beside the replay component, not
in the full Watch chrome. GL400 and Canvas1440; actual GL loss/restore retains
footsteps. `final-model-dom.log`:27 checks including real engine construction/
send, explicit1/4/8 cursor timing, target sizes and no boss marks in fresh towns.

`source-hashes.txt` records renderer/UI/test, WASM and actual save identities.
The immutable inputs are already archived in
`docs/evidence/cut203/earned-kits.tar.gz`. To replay archived scratch harnesses,
copy them to `scratchpad/cut212/` and extract the earned archive to
`scratchpad/cut203/earned/`, then run from repository root. The Vite configs
expect this checkout path; adjust the root for another checkout.

New known-boss metadata and whole-Watch integration need their separate final
package checks. Earlier baselines must remain unchanged.
